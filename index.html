GitHub, native on iOS.

Octodoge helps you follow activity, search users and repositories, browse code and commits, and manage your GitHub profile from your iPhone.

What you can do

Stay up to date

See the latest events in your news feed and on user and repository pages.

Search GitHub

Find users and repositories, then dive into READMEs, files, branches, and forks.

Read code and diffs

Browse directories, view files, inspect commits, and read pull request-style diffs.

Your profile

View public and private repositories, follow users, and star repos after signing in.

Sign in with GitHub

Octodoge uses GitHub OAuth. Your access token is stored securely in the iOS Keychain on your device. The app talks directly to the GitHub API — there is no Octodoge backend collecting your data.

Need help? Visit the support page. Read how we handle data in our privacy policy.
