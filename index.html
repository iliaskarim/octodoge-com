GitHub, native on iOS.

Octodoge helps you follow activity, search users and repositories, browse Issues, Pull Requests, and Actions, and manage your GitHub profile from your iPhone.

What you can do

Stay up to date

Your News Feed shows recent GitHub activity from people and repositories you follow.

Search GitHub

Find users and repositories, then browse branches, forks, directories, and source files.

Read code and diffs

View commit history, inspect changes, and read diffs in a layout built for mobile.

Issues and pull requests

Browse open and closed Issues and PRs, follow the discussion, inspect diffs, and see checks.

Actions

Browse workflow runs, then drill into jobs, steps, and logs.

Your profile

Sign in with GitHub to see your public and private repositories, follow users, and star repos.

Sign in with GitHub

Octodoge uses GitHub OAuth. Your access token is stored securely in the iOS Keychain on your device. The app talks directly to the GitHub API — there is no Octodoge backend collecting your data.

Need help? Visit the support page. Read how we handle data in our privacy policy.
